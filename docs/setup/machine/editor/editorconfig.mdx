# EditorConfig

[EditorConfig](https://editorconfig.org/) enables us to configure basic file formatting and indentation configuration across many editors.

## Installation

Installation depends on your platform.

<Tabs groupId="editor" queryString="editor">
  <TabItem value="vscode" label="VS Code">
    Install the [`EditorConfig.EditorConfig`](https://marketplace.visualstudio.com/items?itemName=EditorConfig.EditorConfig) extension.
  </TabItem>

  <TabItem value="zed" label="Zed">
    Install the [`editorconfig`](https://github.com/notpeter/editorconfig-zed) extension.
  </TabItem>
</Tabs>
