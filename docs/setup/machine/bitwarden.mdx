# Bitwarden

[Bitwarden](https://www.bitwarden.com/) is our password manager.

## Installation

### Desktop application

Install the Desktop application following the [vendor's instructions](https://bitwarden.com/download/) for your platform.

We strongly advise using SSH agent, which can be enabled from the app's settings.

### `bw` CLI

Install the `bw` CLI following the [vendor's instructions](https://bitwarden.com/download/) for your platform.

Don't forget to `bw login` in the CLI.

### Browser extensions

Install the browser extensions following the [vendor's instructions](https://bitwarden.com/download/) for your preferred browsers.
